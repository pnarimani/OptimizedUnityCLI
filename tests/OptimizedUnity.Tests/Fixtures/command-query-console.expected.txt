console clear: Clear the captured log buffer and the Unity Editor console.
console get: Get captured Unity console output (Editor or Player; supports tail, level filtering, and follow via a cursor)
    tail:int32=100  Maximum number of most-recent entries to return
    level:string=log  Minimum severity to include: log | warn | error
    since:int64=-1  Cursor: only return entries newer than this seq. Use the 'cursor' from a previous response to follow.
    since_session:string  Session the 'since' cursor came from: pass the 'session' from a previous response. A cursor from another session is refused and the tail returned with reset=true.
console status: Console ground truth and buffer counters without pulling entries: compile-failure flag, Editor console counts, and the buffer's retained counts and cursor.
console write: Write a message to Unity console
    message:string!  Message to log to console
    level:string=info  Log level: info, warning, error
(unity command <name> --help shows a command's parameters and usage)
